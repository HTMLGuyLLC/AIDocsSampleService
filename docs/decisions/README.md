# Company decisions

Short records of choices that someone, or some agent, might otherwise undo. These are company-wide.
Project decisions live in each project (for example `orders-api/docs/decisions/`).

Number them in order. Never edit an accepted one to mean something else: write a new one that replaces it, and mark the old one `Status: replaced by 000N`.

| # | Decision |
|---|---|
| [0001](0001-one-parent-folder.md) | All repos live in one parent folder, with a router `AGENTS.md` |

Template:

```md
# 000N: <the decision in a few words>

Status: proposed | accepted | replaced by 000N

## Decision
## Why
## What this means
```
