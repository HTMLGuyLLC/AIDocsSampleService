# Choosing a model

| Job | Model | Effort |
|---|---|---|
| Most everyday work | Opus | Low |
| Following a clear plan | Sonnet | Medium |
| Simple, mechanical jobs: renames, lookups | Haiku | Low |
| Checking the cheaper models' work | Opus | Low or medium |
| Genuinely hard problems | Opus | High |

- Hand simple work to a cheaper model as a subagent, then have Opus check it.
- Judge cost per finished task, not per token. Count retries.
- Unsure between two models? Use the stronger one.
