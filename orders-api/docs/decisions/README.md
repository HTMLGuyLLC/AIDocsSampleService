# Decisions

Short records of choices that someone, or some agent, might otherwise undo.
Number them in order. Never edit an accepted one to mean something else: write a new one that replaces it, and mark the old one `Status: replaced by 000N`.

Template:

```md
# 000N: <the decision in a few words>

Status: proposed | accepted | replaced by 000N

## Decision
## Why
## What this means
```
